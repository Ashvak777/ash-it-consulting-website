# ASH IT Consulting

A responsive enterprise consulting website for ASH IT Consulting Inc., focused on AI systems, Microsoft automation, cloud modernization, data intelligence, and public-sector delivery.

## Local preview

```sh
python3 -m http.server 4173 --directory dist
```

Then open `http://127.0.0.1:4173`.

## Contact flow

The inquiry form validates required fields and opens a pre-addressed email draft to `ashvak@ashitconsulting.ca`; no submitted form data is stored by the static site.
